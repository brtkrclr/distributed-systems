# Distributed Systems Internals

A companion to [System Internals](https://github.com/brtkrclr/system-internals). That one goes from bits to containers on a single Linux machine. This one starts where it stops: what happens when one machine isn't enough.

Like the first one, it builds up from the fundamentals step by step, with ASCII diagrams and **🔗 Connections** boxes that show where each concept reappears. It is written with system design / NALSD interview prep in mind, so it uses real numbers, envelope math and a URL shortener as the running example.

Start reading at [DistributedSystems.md](DistributedSystems.md).
